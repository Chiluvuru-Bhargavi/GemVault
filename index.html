03 // CORE_ARCHITECTURE

Separation of Concerns: Gating vs. Interception.

How GemVault orchestrates foreground configuration with background event dispatching in zero-latency Kotlin.

MainActivity.kt
STATE & PRIVILEGE GATING
  • Pre-Flight Service Audit: Queries Settings.Secure to verify active accessibility bindings before committing lock timers.
  • Monotonic State Persistence: Stores hardware timestamps and remaining durations in encrypted SharedPreferences.
  • DevicePolicyManager Coordinator: Initiates ACTION_ADD_DEVICE_ADMIN for Strict Mode and schedules automated teardown.
  • Zero Residual Footprint: Completely ceases background operations once countdown expires.
ShortsBlockerService.kt
BACKGROUND EVENT INTERCEPTOR
  • Event-Driven Triggers: Subscribes exclusively to TYPE_WINDOW_STATE_CHANGED & TYPE_VIEW_CLICKED. Zero active polling.
  • Recursive Node Inspection: Inspects view IDs for reel_recycler, shorts_container, and bottom navigation indices.
  • Millisecond Back Action: Immediately invokes performGlobalAction(GLOBAL_ACTION_BACK) upon Short detection.
  • Deterministic Disposal: Explicitly calls node.recycle() inside every traversal branch to ensure 0.0 MB memory leaks.
