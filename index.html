    Dedicated Timer 2: ig_timer_end_elapsed runs fully independently of Timer 1 on its own monotonic anchor.
  • 🔒
    Strict Mode: GLOBAL_ACTION_HOME fires the instant com.instagram.android opens.
  • ✅
    Non-Strict Mode: Debounced back on Reels viewpager detection. DMs, profiles & feed photos remain accessible.

Time-Travel Defense

Conventional blockers read System.currentTimeMillis(). Moving the system date forward in Settings causes their timers to expire instantly. GemVault anchors both yt_timer_end_elapsed and ig_timer_end_elapsed to SystemClock.elapsedRealtime()—counting continuous hardware milliseconds since boot, including deep sleep. 04 // CORE_ARCHITECTURE

Separation of Concerns: Gating vs. Interception.

How GemVault orchestrates foreground configuration with background event dispatching in zero-latency Kotlin across YouTube and Instagram.

MainActivity.kt
STATE & PRIVILEGE GATING
  • 3-Tier Navigation Coordinator: Manages Dashboard (Main Hub with live status badges), YouTube Settings (Timer 1), and Instagram Settings (Timer 2) with back-stack integrity.
  • Dual Monotonic State Persistence: Stores independent hardware timestamps (yt_timer_end_elapsed & ig_timer_end_elapsed) in encrypted SharedPreferences.
  • Anti-Impulse Rule Locking: Freezes the respective Strict Mode toggle the instant a timer starts, preventing impulsive edits mid-session.
  • DevicePolicyManager Coordinator: Initiates ACTION_ADD_DEVICE_ADMIN for Strict Mode and schedules automated teardown upon session expiry.
ShortsBlockerService.kt
UNIFIED ACCESSIBILITY WORKER
  • Unified Event Filter: Monitors window changes strictly for com.google.android.youtube and com.instagram.android. Drops all other apps instantly to protect battery.

  • Calibrated Debounce Navigation: Uses performBackWithDebounce to eject from Reels feeds without exiting active DM threads or search queries.
  • Deterministic Disposal: Explicitly calls node.recycle() inside every traversal branch to ensure 0.0 MB memory leaks.
